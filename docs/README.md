## 历史报告里的命令怎么用

这些报告写于工具脚本还在仓库根目录、且用 `.cjs` 扩展名的时期，
其中的 `node _bf_xxx.cjs` 之类命令**未随重构更新**。

**换算表见 [`tools/README.md`](../tools/README.md) 的「新旧路径对照表」**，例如：

```bash
node _e2e_bf_headless.cjs    →  node tools/bf/headless.js
node _test_mahjong_logic.cjs →  node tools/test/mahjong-logic.js
node _bf_patch.cjs xxx.json  →  node tools/dev/patch-literal.js tools/patch/jobs/xxx.json
```
