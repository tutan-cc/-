### 3.1 数据层（策划改这里，引擎不改）

节点 Schema：

```js
nodeId: {
  loc:"rent", name:"出租屋 · 房东的底线", day:1, per:0, ch:1, mood:"calm",
  shots:[ { v:"video/x.mp4#t=20", t:"台词", who:"芳姐", bg:"radial-gradient(...)" } ],
  inter:{ type:"choice|quiz|qte|dodge|stock|circuit|memory|talk|fight|mahjong", ... },
  after:[ ... ],            // 交互后的补镜
  next:["park"], end:true,  // 后继链 / 章末标记
  endTeaser:"第二章预告…"
}
```

效果对象 `r` 合法键：`cash/cha/phy/int`、`bond:{id:n}`、`bondAll:n`、`xp:n`、`flags:[..]`、`item:"id"`、`bonus:{need:{...}}`。

### 3.2 状态层与存档

- `restore(raw)` 是**唯一入口**，四层校验：量纲 → 引用白名单（`done/achv` 必须存在于内容表）→ 状态机边界（`active.shot` 越界丢弃）→ 子系统缺省补齐（旧档自动迁移）。
- 坏档一律返回 `null`，**绝不污染 UI**；手改存档必须拼写正确，否则整份被拒。
- 存档点：状态变更 + 电影层每 4s + `pagehide` + `visibilitychange`。
- `S.active={node,phase,shot}` → **中途退出可原地续播**；支持导出/导入 JSON。

### 3.3 演出层（三级画面兜底）

```
视频 →（error / 2.6s 无画面）→ 剧照 + Ken Burns → 动态渐变
```
- `mediaToken` 递增令牌：快速切镜时旧回调作废（视频与剧照都有竞态保护）
- 首帧就绪才淡入；`#shotbar` 分镜进度条；`☰ 台词`回顾（200 条上限，随存档）
- 章节卡（CHAPTER ONE/TWO）转场；胶片颗粒/扫描线/暗角质感层

### 3.4 音频与配音

| 层 | 实现 |
|---|---|
| BGM | `AudioSys` WebAudio 实时合成 5 情绪（calm/city/tense/night/dark），零音频文件 |
| 音效 | click / ding / good / bad，振荡器合成 |
| 剧情配音 | `voMode` 三态：**real（真人原声）→ tts（合成）→ off**；缺真人自动回退 TTS；BGM 自动闪避到 14% |
| 麻将语音 | `mahjong.js` 内 45 条预加载缓存，后一条打断前一条，`localStorage.mjVoiceOn` 持久化 |

## 四、玩法层：11 类玩法与实现位置

| 玩法 | 数据 type | 实现要点 |
|---|---|---|
| 三选一选择 | `choice` | 选项预览效果；`needFlag`/`cost` 不满足则**灰显并说明原因** |
| 限时答题 | `quiz` | `QUIZSETS.lib/.biz` 两套题库；12s + 装备/等级/消耗品加成 |
| 时机 QTE | `qte(mode:"timing")` | 光标往返，绿区宽度 = `min(50, 14+体魄×0.8+窗口加成)` |
| 连打 QTE | `qte(mode:"mash")` | 6 秒计数，进度条反馈 |
| 躲避 | `dodge` | Canvas：数据块下落，判定带宽随智慧，生命 = 3 + 装备/等级/消耗品 |
| 股市波段 | `stock` | Canvas K 线，六日买卖，本金 = 1200 + 加成 |
| 线路取证 | `circuit` | 三段线路旋转归位（整数状态 + 全 0 校验） |
| 信号复原 | `memory` | 累计器驱动（非 setInterval），3 组序列，错 3 次中断 |
| **谈判博弈** | `talk` | 行动力 + 明牌意图 + 施压/让利/试探；**信任/筹码**双条；**羁绊接入**（红姐≥20→筹码+3、顾曼≥20→底线−8） |
| **打斗** | `fight` | 回合制格斗：生命 = 70+体魄×1.6+加成；直拳/组合拳/低扫/抱架/读招；**精准招式触发时机判定，命中伤害 ×1.9**；对手明牌轮转；失败走"惨胜"保底 |
| **麻将** | `mahjong` | 委托 `mahjong.js`（见第五节） |

## 六、3D 沙盘（`map3d.js`）

- `THREE.OrthographicCamera` 等距机位；拖拽旋转（阻尼）/ 滚轮缩放 / 射线拾取点击进入剧情
- **InstancedMesh 合批**（按几何+材质）+ 每地点**主题色实例着色**；`CanvasTexture` 精灵标签三态（avail 光环+自发光+呼吸脉冲 / done 压暗 / locked 灰）
- `setMood(mood)` 与剧情节点联动（5 套雾色光照，含过渡）；右下角小地图（第二正交相机）
- **优雅降级**：无 WebGL 或 THREE 缺失 → `mount()` 返回 false → 自动回落 2D SVG；HUD「🧭 切 2D/3D」手动切换
- 过场时 `map3dPause(true)` 卸载 3D，回沙盘再挂载（软件渲染下避免占满主线程）

## 十、工程规范与踩坑记录（重要，避免重犯）

1. **Node 批量改 HTML/JS 必须用函数式替换** `str.replace(pat, () => rep)`——普通字符串替换里 `$&`/`$1` 会被当替换模式，曾导致 index.html 被写坏。
2. **PowerShell 5.1 读无 BOM 的 UTF-8 脚本会乱码**：脚本统一存为 **UTF-8 with BOM**。
3. **PowerShell 变量名大小写不敏感**：`$n` 会覆盖 `$N`，曾导致 K 线只画一根。
4. **SAPI 语音**：本机 `System.Speech` 与 WinRT 语音均报错，只有 **COM `SAPI.SpVoice`** 可用；`SpMemoryStream.GetData()` 返回**裸 PCM**，需手工补 44 字节 WAV 头；沙盒会以 `E_ACCESSDENIED` 拒绝，需完整权限。
5. **沙盒限制**：Chrome 无头需命名管道（被拦），子代理无法提权 → 浏览器验收脚本自带 Trident 降级。
6. **改动纪律**：改大文件前先备份（`*.bak/*.vXXbak`）；语法检查失败立即回滚；禁止留半成品。
